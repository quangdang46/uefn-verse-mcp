# has_description interface

Learn technical details about the has_description interface.

Interface that provides descriptive names or text.

|  |  |
| --- | --- |
| Verse `using` statement | `using { /Verse.org/Presentation }` |

## Members

This interface has data members, but no functions.

### Data

| Data Member Name | Type | Description |
| --- | --- | --- |
| `Name` | `?message` | The display name of this entity. |
| `Description` | `?message` | The full description of this entity. |
| `ShortDescription` | `?message` | A shortened description of this entity. |
