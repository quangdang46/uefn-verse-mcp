# Accessing Brand Content

Learn how to access assets to create brand islands.

![Accessing Brand Content](https://dev.epicgames.com/community/api/documentation/image/c77478cb-ff06-49ac-82c7-99a4cb023094?resizing_type=fill&width=1920&height=335)

###### Prerequisite topics

In order to understand and use the content on this page, make sure you are familiar with the following topics:

- [Install and Launch Fortnite](https://dev.epicgames.com/documentation/fortnite/install-and-launch-fortnite-creative-and-unreal-editor-for-fortnite)

As a developer, you can build islands with curated [assets](https://dev.epicgames.com/documentation/fortnite/fortnite-glossary#asset) designed around a particular brand that Epic has partnered with. These [brand islands](https://dev.epicgames.com/documentation/fortnite/fortnite-glossary#brand-island) offer players the chance to explore immersive, recognizable worlds.

You can access the feature set for each brand from Fortnite Creative and Unreal Editor for Fortnite (UEFN). However, some assets and templates are only available in UEFN.

From this page, learn how to access the brand content in Creative and UEFN, and how to enroll in the Fortnite Developer Program with the correct agreements to publish brand islands.

You can get started building in Creative, just like any other project, from the console.

In Creative, you can find the brand-specific assets in the **Content** menu. Each brand has its own category, with assets grouped accordingly.

## Publish Your Island

To publish your island, you must be a member of the Fortnite Developer Program and have signed the Intellectual Property (IP) Partner Licensing Agreement. Already signed the agreement to create brand islands? You’re all set!

For detailed answers to common IP questions such as usage rights, licensing, and permissible content, see the [IP FAQ](https://legal.epicgames.com/en-US/epicgames/intellectual-property-faq) article.

### If You're Already Enrolled as an Fortnite Developer

If you are already enrolled in the Fortnite Developer Program, on the program home page, you can click **Get Started**. A pop-up window appears with the agreement for you to accept. Once you do, you’re all set — get building!

[![](https://dev.epicgames.com/community/api/documentation/image/d0922106-0fc3-4098-b57c-77b108b9c993?resizing_type=fit)](https://dev.epicgames.com/community/api/documentation/image/d0922106-0fc3-4098-b57c-77b108b9c993?resizing_type=fit)

### If You're Not Yet Enrolled as an Fortnite Developer

If you have not enrolled in the Fortnite Developer Program, you first need to meet the eligibility requirements for the program.

Click **Enroll Now** and follow the prompts. To learn more about signing up for the program, see the [Island Developer Program](https://dev.epicgames.com/documentation/fortnite/island-creator-and-engagement-program-in-fortnite-creative).

[![](https://dev.epicgames.com/community/api/documentation/image/66b13717-b611-4244-a55d-7fdb9b812fd6?resizing_type=fit)](https://dev.epicgames.com/community/api/documentation/image/66b13717-b611-4244-a55d-7fdb9b812fd6?resizing_type=fit)

While you’re signing up for the program, you can also sign the IP Partner Licensing Agreement with the other agreements that are required for the program.
