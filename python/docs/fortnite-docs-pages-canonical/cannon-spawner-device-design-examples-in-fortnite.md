# Cannon Spawner Device Design Examples

Let your players shoot, ride, and catapult — all from a single device!

![Cannon Spawner Device Design Examples](https://dev.epicgames.com/community/api/documentation/image/78ef9df9-f752-446a-a86b-8dda1dd7472d?resizing_type=fill&width=1920&height=335)

You can use the **Cannon Spawner** device to add a unique weapon to your island — because it’s also a vehicle, and a way to launch yourself into the air! In this design example, you will learn how to create a unique team game mode themed around two castles at war. Your players will use the cannons to conquer their enemy's castle!

## Devices Used

- 16 x [Player Spawner](https://dev.epicgames.com/documentation/fortnite/using-player-spawn-pad-devices-in-fortnite-creative) devices
- 18 x [Cannon Spawner](https://dev.epicgames.com/documentation/fortnite/using-cannon-spawner-devices-in-fortnite-creative) devices
- 16 x [Objective](https://dev.epicgames.com/documentation/fortnite/using-objective-devices-in-fortnite-creative) devices

You will buiild the castles, add the devices, then set up the game rules with the Island Settings.
