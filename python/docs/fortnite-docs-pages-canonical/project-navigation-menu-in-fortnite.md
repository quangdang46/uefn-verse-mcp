# Project Navigation Menu

Everything you need to manage a project once you select it from the Project page.

![Project Navigation Menu](https://dev.epicgames.com/community/api/documentation/image/fc39fb76-41f4-4d68-b10c-c55922d20da5?resizing_type=fill&width=1920&height=335)

Once you select a project from the Projects page in Creator Portal, you can use the project navigation menu to access publishing information, analytics for the project, any in-game items available in this project, and any Verse runtime errors generated.

Start by selecting a project from the **Projects** page.

[![Open the Projects page in Creator Portal to select a project.](https://dev.epicgames.com/community/api/documentation/image/4b1ed61d-18ca-45ca-bf48-92f69443be4f?resizing_type=fit)](https://dev.epicgames.com/community/api/documentation/image/4b1ed61d-18ca-45ca-bf48-92f69443be4f?resizing_type=fit)

Select a project on the Projects page.

Selecting a project opens the project's **Publishing** page. You will see the project navigation menu displayed in the left sidebar.

The following team roles can change the listing status from the project navigation menu:

- Owner
- Administrator
- Publisher

Team members who have the Collaborator project role won’t be able to change a project's listing status.

### Navigation Menu

The image below shows the project navigation menu, with a table describing each menu option. You can also see that the account-level navigation menu has been minimized to a toolbar to the left of the project navigation menu.

[![The Project Navigation menu displayed for the selected project.](https://dev.epicgames.com/community/api/documentation/image/54610c2f-34d1-46cf-bf33-62a01aaf6d2f?resizing_type=fit)](https://dev.epicgames.com/community/api/documentation/image/54610c2f-34d1-46cf-bf33-62a01aaf6d2f?resizing_type=fit)

The Project Navigation menu displayed for the selected project.

| Menu Item | Description |
| --- | --- |
| **Publishing** | Displays the project's Publishing page. For more information on using this page, see **[Project Publishing Page](https://dev.epicgames.com/documentation/fortnite/publishing-page-features-in-fortnite-creative)**. |
| **Analytics** | Displays the project's Analytics page. For more information on using this page, see [Project Analytics](https://dev.epicgames.com/documentation/fortnite/project-analytics-for-fortnite-games). |
| **In-Island Transactions** | Displays the project's In-Island Transactions page. For more information on using this page, see [Project In-Island Transactions](https://dev.epicgames.com/documentation/fortnite/project-in-island-transactions-in-fortnite). |
| **Technical** | Shows information on Verse runtime errors. For more information on using this page, see Verse Runtime Error Reporting. |
| **Links** | Displays the Links page for this project. For more information on using this page, see [Links](https://dev.epicgames.com/documentation/fortnite/links-in-fortnite-creative). |
